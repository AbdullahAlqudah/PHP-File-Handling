# PHP File Handling Tasks

Nine independent PHP exercises covering file creation, reading, renaming, appending, secure uploads, CSV parsing, log archiving, file locking and directory traversal prevention.

## Run

Copy `PHP-File-Handling` into `C:\xampp\htdocs`, start Apache in XAMPP, and visit `http://localhost/PHP-File-Handling/01-File-Creation/` (or another numbered folder).

Task 3 renames `config.txt` once; restore its name to rerun. Task 8 creates `counter.txt` automatically. Task 9 uses `http://localhost/PHP-File-Handling/09-Safe-Delete/delete.php?file=report1.pdf` and deletes the example file once. For a real application, require authentication, authorization and POST with CSRF protection before deletion. The example PDF is only a test placeholder.
